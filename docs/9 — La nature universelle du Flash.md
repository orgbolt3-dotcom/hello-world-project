# 9. La nature universelle du Flash

Le Flash constitue l’un des éléments fondamentaux de Vitalis.

Il permet à une personne d’exprimer naturellement quelque chose qu’elle recherche, souhaite, propose, offre, organise ou avec quoi elle souhaite entrer en relation.

Le Flash part donc de **l’intention humaine**, et non d’une catégorie commerciale prédéfinie.

## 9.1 Le Flash est une expression d’intention

Un Flash permet d’exprimer une intention réelle.

Cette intention peut concerner ce que l’utilisateur :

- recherche ;
- souhaite ;
- désire ;
- demande ;
- propose ;
- offre ;
- veut organiser ;
- cherche à découvrir ;
- cherche à obtenir ;
- cherche à partager ;
- ou avec quoi il souhaite entrer en relation.

Vitalis doit partir de cette intention telle qu’elle est exprimée.

## 9.2 Un Flash n’est pas nécessairement commercial

Un Flash ne doit pas être considéré comme une simple annonce commerciale.

Il peut notamment représenter :

- un besoin ;
- un désir personnel ;
- une demande d’aide ;
- une proposition ;
- une offre ;
- une recherche de personne ;
- une recherche de partenaire ;
- une activité ;
- une opportunité ;
- une demande particulière ;
- ou toute autre intention pertinente exprimée naturellement.

Vitalis ne doit donc pas obliger l’utilisateur à transformer son intention en produit, service ou transaction lorsqu’elle ne l’est pas.

## 9.3 Le langage naturel est le point de départ

L’utilisateur doit pouvoir exprimer son Flash avec ses propres mots.

Il peut notamment utiliser :

- du texte ;
- la voix ;
- une formulation courte ;
- une formulation détaillée ;
- ou alterner entre voix et clavier.

Vitalis comprend ensuite cette expression et la structure afin de la rendre exploitable.

L’utilisateur n’a donc pas besoin de connaître à l’avance la structure interne attendue par le système.

## 9.4 Comprendre sans inventer

Vitalis peut identifier et structurer les informations réellement présentes dans l’expression de l’utilisateur.

Selon le Flash, cela peut notamment concerner :

- l’intention ;
- le sujet ;
- la description ;
- les caractéristiques ;
- la quantité ;
- le budget lorsqu’il est réellement exprimé ;
- la zone ;
- le rayon lorsqu’il est réellement exprimé ;
- la période ou la disponibilité ;
- la visibilité ;
- les informations complémentaires ;
- les modalités de mise en relation.

Cependant, **aucune information absente ne doit être inventée**.

Par exemple, si l’utilisateur dit :

> « Je cherche quelque chose de récent et pas trop cher près de moi. »

Vitalis ne doit pas automatiquement transformer cette expression en :

- une année précise ;
- un budget précis ;
- un rayon précis ;
- une zone précise ;

si ces informations n’ont pas réellement été fournies ou confirmées.

L’intelligence consiste à comprendre ce qui est exprimé, à identifier ce qui reste ambigu et, lorsque cela est nécessaire, à demander une précision.

## 9.5 Le Flash peut évoluer

Un Flash peut évoluer au cours de son existence.

Selon son état et les besoins de l’utilisateur, il peut être :

- complété ;
- corrigé ;
- modifié ;
- planifié ;
- publié ;
- suspendu ;
- repris ;
- clôturé ;
- puis archivé.

Une modification importante d’un Flash actif ne doit pas être publiée silencieusement.

L’utilisateur doit pouvoir comprendre ce qui change et valider la nouvelle version lorsque cela est nécessaire.

## 9.6 Le Flash comme pont vers l’action

Le Flash n’est pas uniquement un contenu publié.

Il constitue le point de départ d’une possibilité réelle d’action.

Son parcours peut être résumé ainsi :

**Exprimer → Comprendre → Structurer → Valider → Publier → Découvrir → Agir → Se mettre en relation.**

Chaque étape doit rester cohérente avec l’intention initiale de l’utilisateur.

## 9.7 Le Flash respecte l’intention de son auteur

Vitalis peut aider l’utilisateur à mieux formuler et structurer son intention.

Il ne doit cependant jamais la remplacer par sa propre interprétation.

L’intelligence de Vitalis sert à :

- comprendre ;
- clarifier ;
- structurer ;
- faciliter ;
- accompagner.

Elle ne sert pas à décider à la place de l’utilisateur ce que celui-ci voulait dire.

### Principe directeur

> **Un Flash est une expression structurée d’une intention réelle. Il peut représenter une demande, un besoin, un désir, une aide, une proposition, une recherche, une opportunité ou toute autre intention pertinente. Vitalis doit comprendre cette intention sans la dénaturer ni inventer ce qui n’a pas été exprimé.**
